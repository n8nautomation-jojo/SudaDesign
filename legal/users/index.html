Privacy Policy — Suda Design

Application: Suda Design (Android Edition) • Effective Date: November 4, 2026 • Contact: support@sudadesign.app

Zero-Data Collection Guarantee: Suda Design is engineered as an offline-first, private creative studio. We collect, store, transmit, process, and share zero bytes of personal data, device identifiers, analytics, or creative files.

1. Architectural Data Handling Audit

A rigorous static and binary inspection of the application manifest (AndroidManifest.xml), native libraries (libphotocraft_android.so), and packaging dependencies confirms the following behavior:

Data Category Technical Audit Result Verified Production Behavior
Personal Identifiers Zero account or identity code No name, email, phone number, or ID collected
Accounts & Profiles Zero authentication systems Operates without login or credentials
Analytics & Telemetry Zero tracking SDKs No behavioral tracking or event telemetry
Crash Reporting SDKs Zero third-party crash monitors Diagnostic logs stay locally on device
Advertising Networks Zero ad networks or attribution SDKs No ads displayed, no Advertising ID accessed
Network Permissions Manifest omits android.permission.INTERNET Core studio operates 100% offline

2. Local Storage & File Access (SAF)

Suda Design uses the Android standard Storage Access Framework (SAF):

  • The application does not request broad file access permissions (such as MANAGE_EXTERNAL_STORAGE or READ_MEDIA_IMAGES).
  • Files are accessed exclusively when you open them using the Android system file picker (via ACTION_OPEN_DOCUMENT or ACTION_CREATE_DOCUMENT).
  • Temporary file handles are retained solely during active editing sessions and are discarded upon closing.
  • Your creative PSD files, exported images, and custom imported fonts never leave your device.

3. International Privacy Framework Alignment

Because Suda Design does not transmit or process personal data on external servers:

  • GDPR (European Union): Regulation (EU) 2016/679 compliance is achieved naturally as no personal data is transferred or controlled remotely.
  • CCPA / CPRA (California, US): Suda Design does not sell, share, or collect personal consumer information as defined in Cal. Civ. Code § 1798.100 et seq.
  • PDPL (Kingdom of Saudi Arabia): Royal Decree No. M/19 sovereignty is preserved; all user documents remain exclusively under user control.
  • COPPA (Children's Online Privacy): The application collects no personal information from children under 13.

4. Security and User Responsibilities

Because all designs and exported artwork are stored locally on your device, data security relies on your Android device-level safeguards (device passcode, biometrics, disk encryption, and operating system updates). Users are encouraged to maintain regular backups of their creative files.
